Compactador de Pastas em ZIP - versão simples.

	Todas as pastas de origem selecionadas viram 1 ÚNICO arquivo .zip no destino.
	O nome do .zip leva a data e a hora do backup no final.
	Quando já existem 5 ou mais .zip no destino, apaga todos menos o mais recente antes de criar o novo (fica sempre com no máximo 2 depois da limpeza).
	A tela mostra o histórico dos backups já feitos na pasta de destino.

Interface gráfica com CustomTkinter, tema Escuro/Claro, lista de pastas de origem editável e configurações salvas em config.json.
